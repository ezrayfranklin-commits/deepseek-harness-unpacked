# DeepSeek Harness Unpacked

[简体中文](README.md) · [English](README.en.md) · [Español](README.es.md) · [日本語](README.ja.md)

An interactive source-code guide to the DeepSeek Harness web client, available in Simplified Chinese, English, Spanish, and Japanese.

## Read online

**[Open DeepSeek Harness Unpacked →](https://ezrayfranklin-commits.github.io/deepseek-harness-unpacked/)**

## What the site covers

- The Cordis plugin tree and Web Profile, traced through the actual source
- An animated walkthrough of a message moving through the Agent Loop
- All 52 tools grouped by responsibility, with parameters, packages, and source locations
- Commands registered by the web client and a practical source-reading route
- Instant switching between Simplified Chinese, English, Spanish, and Japanese

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

# DeepSeek Harness Unpacked

[简体中文](README.md) · [English](README.en.md) · [Español](README.es.md) · [日本語](README.ja.md)

DeepSeek Harness の Web クライアントをソースコードから読み解くインタラクティブガイドです。簡体字中国語、英語、スペイン語、日本語で閲覧できます。

## オンラインで読む

**[DeepSeek Harness Unpacked を開く →](https://ezrayfranklin-commits.github.io/deepseek-harness-unpacked/)**

## このサイトで分かること

- 実際のソースをたどって理解する Cordis プラグインツリーと Web Profile
- メッセージが Agent Loop を通る過程を示すアニメーション
- 役割別に整理した 52 個のツールと、その引数、パッケージ、ソース位置
- Web クライアントに登録されたコマンドと、実践的なソース読解ルート
- 簡体字中国語、英語、スペイン語、日本語の即時切り替え

## ローカルで実行

```bash
npm install
npm run dev
```

## ビルド

```bash
npm run build
```

このガイドは [deepseek-ai/deepseek-harness](https://github.com/deepseek-ai/deepseek-harness) の公開ソースコードとアーキテクチャ文書に基づく非公式資料です。

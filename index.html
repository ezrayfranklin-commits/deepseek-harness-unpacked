00 / THESIS
“不存在需要打补丁的特权内核。”

Harness 最重要的设计不是又一个 Agent Loop，而是让模型适配器、工具注册表、会话日志，乃至循环本身都成为可挂载、可替换、可卸载的 Cordis 插件。

01

一切皆插件

能力通过共享上下文注册；插件卸载时，副作用随之撤销。

02

日志即真相

模型可见的输入必须可由 SessionEvent 日志完整重建。

03

Seam 可替换

接口、Provider 与 Consumer 分离，让本地能力可整体切换到远程沙箱。

02 / AGENT LOOP

一次消息的
完整旅程

Turn 可以包含多个 Step；每个 Step 都是一次模型请求及其工具调用。横向滚动，跟踪控制权的交接。

01INPUT

followup()

消息进入 Agent inbox，唤醒 driver。

agent/inbox/inserted
02PERSIST

Turn 开启

领取输入，并在会话日志写入边界。

turn/start
03ASSEMBLE

构造上下文

拼接提示词片段、工具 schema 与历史。

agent/pre-step
04STREAM

模型生成

流式 chunk 先落日志，再投影到 UI。

assistant/chunk*
05EXECUTE

工具批次

按屏障与滚动池调度，结果保持模型顺序。

tool/call → result
06SETTLE

继续或结束

仍欠工作则下一 Step，否则关闭 Turn。

turn/end
03 / WEB CLIENT

UI 不是状态源
而是事件投影

浏览器端通过连接层驱动 Agent，并消费 session/event。原始 chunk 被保留，因此刷新、回放与流式 UI 可以共享同一事实源。

# DeepSeek Harness Unpacked

[简体中文](README.md) · [English](README.en.md) · [Español](README.es.md) · [日本語](README.ja.md)

Una guía interactiva del código fuente del cliente web de DeepSeek Harness, disponible en chino simplificado, inglés, español y japonés.

## Leer en línea

**[Abrir DeepSeek Harness Unpacked →](https://ezrayfranklin-commits.github.io/deepseek-harness-unpacked/)**

## Contenido del sitio

- El árbol de plugins de Cordis y el Web Profile, explicados desde el código real
- Un recorrido animado de un mensaje a través del Agent Loop
- Las 52 herramientas agrupadas por función, con parámetros, paquetes y archivos fuente
- Los comandos registrados por el cliente web y una ruta práctica para leer el código
- Cambio inmediato entre chino simplificado, inglés, español y japonés
